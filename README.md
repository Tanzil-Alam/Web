# 🚀 Developer & Hardware Portfolio

Welcome to the source code repository for my personal developer portfolio website. This website serves as an interactive hub showcasing my work across **Hardware Engineering**, **Embedded Systems**, **3D Design & Prototyping**, and **Creative Coding & AI Engineering**.

---

## 📌 Project Overview

This website is a lightweight, responsive, dark-themed portfolio built using pure HTML5 and CSS3. It is designed with clean typography, high contrast visual hierarchy, and full mobile responsiveness.

### Key Sections
1. **Hero Section:** Introduction outlining core domains in robotics, microcontrollers, and hardware development.
2. **About Me:** Overview of expertise in hardware development, physical device design, and leading end-to-end engineering initiatives under **Voltx**.
3. **Skills & Works:** A structured overview of core technical competencies divided into three domains:
   - **Hardware Engineering & Embedded Systems:** ESP32, ESP32-C3, ESP8266, Arduino platforms, nRF24L01 / CC1101 RF modules, and SSD1306 OLED displays.
   - **3D Design & Hardware Prototyping:** Custom enclosures, Bambu Studio slicing optimization, boolean mesh modeling, and embossed tolerance design.
   - **Creative Coding & AI Engineering:** AI workflow automation, MediaPipe gesture tracking, Three.js 3D rendering, and C++/Python script development.
4. **Contact & Community:** Quick-access links to reach out for direct collaboration and community channels across YouTube, Facebook, X (Twitter), and Instagram.

---

## 🛠️ Tech Stack & Features

- **Frontend:** HTML5, Modern CSS3 (CSS Grid, Flexbox, Custom CSS Animations & Transitions)
- **Typography & Styling:** System UI font stack with high-contrast color scheme (`#000000`, `#121316`, `#CCFF00` accents)
- **Responsiveness:** Fluid media queries catering to Desktop, Tablet, and Mobile screens
- **Iconography:** Scalable Vector Graphics (SVG) for fast rendering and zero resolution loss
