# Developer & Hardware Portfolio

Welcome to the repository for my personal developer portfolio website. This platform showcases my projects across **Hardware Engineering**, **Embedded Systems**, **3D Design & Prototyping**, and **Creative Coding & AI Engineering**.

---

## Project Overview

This site is a lightweight, responsive, dark-themed portfolio built with clean HTML5 and CSS3. It focuses on readable typography, clear visual hierarchy, and full mobile optimization.

### Key Sections

* **Hero Section:** Introduction outlining core technical focus areas in robotics, microcontrollers, and hardware development.
* **About Me:** Overview of expertise in physical device design, embedded firmware, and end-to-end engineering initiatives under **Voltx**.
* **Skills & Works:** Highlights of core technical competencies divided into three primary categories:
* **Hardware Engineering & Embedded Systems:** ESP32, ESP32-C3, ESP8266, Arduino platforms, nRF24L01 and CC1101 RF modules, and SSD1306 OLED integration.
* **3D Design & Hardware Prototyping:** Custom enclosure modeling, Bambu Studio slicing optimization, boolean mesh workflows, and tolerance design.
* **Creative Coding & AI Engineering:** AI workflow automation, MediaPipe gesture tracking, Three.js 3D rendering, and C++/Python script development.


* **Contact & Community:** Links for direct inquiry and community interaction across social platforms.

---

## Tech Stack & Design

* **Frontend:** Standard HTML5 and CSS3 (utilizing Flexbox, CSS Grid, and custom keyframe animations).
* **Styling & Theme:** System UI typography with high-contrast elements and accent colors (`#000000`, `#121316`, `#CCFF00`).
* **Responsiveness:** Fluid layout queries designed to scale cleanly across desktop, tablet, and mobile screens.
* **Assets:** Vector graphics (SVG) for lightweight, high-resolution rendering.

## Running Locally

1. **Clone the repository:**
```bash
git clone https://github.com/xiamcommunity-max/portfolio.git

```


2. **Navigate to the directory:**
```bash
cd portfolio

```


3. **Open in browser:**
Open `index.html` directly in any web browser or use an extension like VS Code Live Server.
